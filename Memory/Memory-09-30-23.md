## 关键修正:侧边栏选中"外面套了一层"

**根因**:macOS 的 `List(selection:)` 由 `NSTableRowView` 在**行背景之上**绘制系统选中胶囊,
`.listRowBackground` 只能在其外面再画一层 —— 所以圆角永远改不掉,看起来就是"外面套了一层",
而且鼠标按下(系统胶囊)和选中(我的图层)两套样式并存。

**修法**:不再用 `List(selection:)`。改用 `List { … }` + 自绘 `SidebarCategoryRow`
(selected / hovered / idle 三种状态**共用同一个 shape 和圆角**),点击自己设 `selection`;
键盘导航用 `.onMoveCommand` + `moveSelection(_:)` 补回来(方向键上下移动展开后的分类列表)。
行还补了 `accessibilityAddTraits(.isSelected)`。

> 教训:**凡是"系统绘制在上面"的装饰,不要试图用背景层去改** —— 要么接受它,要么自己接管整行。
