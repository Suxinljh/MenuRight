## 改了什么

只动两个文件 + 一处自测注入（注入是上一轮就有的）：

- `MenuRight/App/Settings/CustomCompressionSheet.swift`
  1. **位置**：新加 `struct NativeFolderPicker: NSViewRepresentable`，里面是真 `NSPopUpButton`：
     `bezelStyle = .rounded`、`imagePosition = .imageLeading`、`cell?.lineBreakMode = .byTruncatingMiddle`，
     菜单项图标用 `NSWorkspace.shared.icon(forFile:)`（文件夹**自己的** Finder 图标，带标签颜色——参考图里那个粉色文件夹就是这么来的）。
     菜单内容由**纯函数** `NativeFolderPicker.menu(directory:recent:chooseTitle:) -> [Entry]` 生成：
     当前文件夹 → 本次对话框访问过的文件夹（`@State private var recents: [URL]`，去重、最多 5 个）→ 分隔线 → 「选择…」（`url == nil`）。
     `Coordinator.picked` 把 `nil` 翻译成「开面板」，并先把弹窗选回第 0 项（否则按钮会一直显示「选择…」）。
     行里还留了一个单独的「⌄」小按钮（`Button { chooseDirectory() }`），和参考图一模一样：
     弹出菜单 + 小按钮都能开系统 `NSOpenPanel`。原来的「文件夹图标 + 名称 + 上级路径」自绘控件和 `abbreviatedParent` 一起删了。
  2. **分卷压缩前的空隙**：`Picker` 的 `.frame(width: 140)` → `.fixedSize()`。根因与上一轮格式/模式完全相同
     （`NSPopUpButton` 会把标题在给定宽度里居中，看着像半行空档），这是最后一处。
  3. **加密压缩整行宽度**：密码框 `.frame(width: 200)` → `.frame(maxWidth: .infinity)`；
     选项那一列补 `.frame(maxWidth: .infinity, alignment: .leading)`，整行左右顶到对话框内边。
  4. **加密文件名挪位**：原来独占一行，现在放到「固实压缩」同一行的右端（`HStack(alignment: .firstTextBaseline)` +
     `Spacer(minLength: 24)`），形状与「压缩格式 / 压缩模式」一致；非 7z 时整块不渲染。
- `MenuRightTests/CustomCompressionDialogTests.swift`：+3 例，都打在 `NativeFolderPicker.menu` 这个纯函数上
  （第一项是当前文件夹 / 最后一项是「选择…」且没有 URL / 访问过的文件夹去重）。因为没有断言 AppKit 最终版式，
  我把 `NativeFolderPicker` 从 `private` 改成 internal（同文件在 app 与 tests 两个 target 都编，所以测试够得着）。

## 坑

- `private struct` 在文件作用域等于 fileprivate，另一个 target 的同名源文件看不见 ⇒ 必须去掉 `private` 才能单测。
- 自测进程被 `NSApp.terminate` 结束后偶尔留下 `MenuRight.app/Contents/MacOS/MenuRight.cstemp`，
  下一次构建报 `Command CodeSign failed … invalid or unsupported format for signature`；
  `rm -rf build/DerivedData/Build/Products/Debug/MenuRight.app` 后重建即可（第二次遇到）。
- 沙箱里 `NSHomeDirectory()` 是容器路径，`abbreviatingWithTildeInPath` 不会缩成 `~/…`——本轮把上级路径整块删了，问题自然消失。
- NSViewRepresentable 在 `Grid(alignment: .leadingFirstTextBaseline)` 里没有基线，只能按底边对齐；
  实测 PNG 里「位置」标签和弹出菜单基本齐（差 1–2pt），可以接受，没有为它加自定义 alignmentGuide。
