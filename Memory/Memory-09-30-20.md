## 实现

- `ZipWriter.archive(_:comment:level:)`:EOCD 归档注释(≤64 KiB)+ 可指定 DEFLATE 级别;
  类注释里"不支持 zip 注释"的说法已改正(不支持的是**每条目**注释)。
- `ArchiveCompressionMode`(fast/standard/maximum):ZIP → DEFLATE 1/6/9;`.tar.bz2` →
  BZip2 BlockSize 1/5/9;TAR 与 gz **接受但忽略**(库的 gzip writer 没有级别参数),
  UI 会明说,不假装。
- 契约(纯增量)与 dispatcher 透传:`archiveLabel` / `archiveMode`;未知值回退默认,
  不因为一个旋钮没传就整体失败。
- 测试:标签往返(自研 reader)、无标签→无注释、**模式必须真的改变字节数**(否则对话框就是在骗人)、
  标签在非 ZIP 格式被忽略且仍可解压、模式文案双语、dispatcher 端标签真的写进注释。

## 复盘要点

- 旋钮做成"真参数"而不是 UI 摆设:测试直接断言 maximum 产物小于 fast 产物 —— 这类断言能防止
  将来有人把 mode 接成一个无害的枚举。
- 三方证据链:自研 reader 读回注释 → **系统 `unzip -z` 也读到** → 验证脚本断言,
  比单测更能说明"别的工具认这个注释"。
