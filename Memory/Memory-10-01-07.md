## 现象与取证

选中项文字变白、图标仍是黑的。取像素:

- 选中胶囊底色 `rgb(149,61,150)`,胶囊内图标区最暗像素 **`rgb(0,0,0)`**;未选中行同样 `rgb(0,0,0)`。
  (若图标吃的是 `Color.primary`,浅色底上叠出来不会正好是 0。)
- 资源侧排除:`xcrun assetutil --info Assets.car` 显示 `TemplateMode=template`;
  运行时 `bundle.image(forResource:)` 的 `isTemplate = true`。**不是资源问题。**

## 根因

`.listStyle(.sidebar)` 的 `List` 会**从外层给 label 的图标槽重新套一遍前景色**,
所以行级 `.foregroundStyle` 能到文字、到不了图标。

定位手段(可复用):把整行**离屏渲染**出来取像素 ——
`NSHostingView` + 离屏 `NSWindow` + `cacheDisplay(in:to:)`,再读 `NSBitmapImageRep`。
裸 `VStack` 里该行完全正确(选中行图标白),放进 `List(.sidebar)` 就变黑。

## 五种写法实测(都在 `List(.sidebar)` 内)

| 写法 | 选中行图标 |
|---|---|
| 只在 Label 外层设 `.foregroundStyle`(原状) | 黑 ❌ |
| `.tint(.white)` | 黑 ❌ |
| **在 icon 视图上直接设 `.foregroundStyle`** | **白 ✅** |
| 改用 `HStack` 分别设 | 白 ✅ |
| 在 icon 上设 + `.labelStyle(.titleAndIcon)` | 白 ✅ |

取最小改动:`SidebarCategoryRow` 里抽出 `private var foreground: Color`,
在 `AssetIcon` 上**再设一次** `.foregroundStyle(foreground)`(注释里说明了为什么不是冗余)。
