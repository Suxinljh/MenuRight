## 决策与约定

- **用 HTML `<img>` + `width`/`height` 而不是 Markdown `![...]()`**：截图宽高比差异极大（354×904 竖版菜单 vs 2201×1547 宽版设置窗），
  用同一 `height` 并排对齐才不歪。同级两张图放在一个 `<p align="center">` 里、中间 `&nbsp;&nbsp;&nbsp;`。
- **尺寸留了余量**：GitHub `markdown-body` 约 1012px 宽，并排两张按 `height` 换出来的总宽控制在 ~880px 以内
  （代码主题 466 + Quick Look 397；通用设置 + 文件权限各约 432）——按原图满宽并排会溢出。
- **webp 可直接用于 GitHub README**，无需转 png；`.gitignore` 未忽略 `MenuRight/Resources/images/`（已 `git check-ignore` 确认）。
- 插入后校验：README 里 8 个 `src="..."`（含原有 logo）全部 `-f` 命中，7 张图无一张遗漏未引用。
- 未改动 `README.md` 中「图片按功能分区」以外的内容：AGENTS.md 要求 PR 聚焦当前任务。
