## 图标

`MenuRight/MenuRight.icon`(Icon Composer 包:icon.json + Assets/*.svg)**原本只是 pbxproj 里的一个文件引用,
从未加入 App target 的 Resources 阶段**,因此编译出来一直是默认图标。修法:补一个 `PBXBuildFile`
放进 Resources phase(与 BrandAssets.xcassets 并列),不改 `ASSETCATALOG_COMPILER_APPICON_NAME`。
结果:`MenuRight.icns` 与 `Assets.car` 进包,Info.plist 的 `CFBundleIconName`/`CFBundleIconFile` 均为 `MenuRight`。
