## 改法(全部在 UI 层,文案字符串一个没删)

`MenuRight/App/Settings/CustomCompressionSheet.swift`:

- 5 段说明(`archiveModeNote` / `archiveEncryptionNote` / `archiveEncryptSevenZipNote` / `archiveSplitNote` /
  `archiveSolidNote`)＋ `archiveEncryptFormatsNote` ＋ 「标签」下那行 `archiveLabelZipOnly` 全部不再渲染,
  改成 `.help()` 悬停提示 —— 规则还在,只是不占版面。
- 密码本菜单:`Menu(store.text(.archivePasswordBookPick))` → `Menu { … } label: { Image(systemName: "key") }`
  ＋ `.menuStyle(.borderlessButton)`,提示里保留「从密码本选择」。
- 「压缩格式 / 压缩模式」的两个 `Picker` 去掉 `.frame(width: 150)`,改 `.fixedSize()`。
  **教训**:`.frame(width: 150)` 时 `NSPopUpButton` 把标题在自己 150pt 里**居中**,看起来就像标签和选项之间空了半行;
  `.fixedSize()` 后只剩 `spacing: 12`,和「保存为」的 `Grid(horizontalSpacing: 12)` 视觉一致。
- 「位置」改成整行可点的控件:蓝色 `folder` 图标 + 文件夹名 + 上级路径(`.truncationMode(.head)`),点它开 `NSOpenPanel`
  (原来那条 `chooseDirectory()` 的 `panel` 代码不变)。三个控件统一 `Self.controlWidth = 300`。
- 「固实压缩」改用计算绑定 `solidBinding`:`Binding(get: { solidIsAvailable && solid }, set: { solid = $0 })`。
  以前非 7z 时是「勾着但灰」—— 一个打了勾的死勾选框读起来像「开着」,现在显示成未勾 + 置灰,`solid` 状态仍留给 7z。
- 「保存为 / 标签 / 位置」包进 `HStack { Spacer(minLength: 0); Grid { … }; Spacer(minLength: 0) }` 整体居中。

`MenuRight/App/MenuRightApp.swift`(DEBUG 自测):新增可选 env `MENURIGHT_SELFTEST_ARCHIVE_DIALOG_PASSWORD_BOOK=1`,
给对话框注入一个**内存**密码本(一条示例条目 `webp_images.zip` / `hunter2`),这样钥匙按钮能出现在版式 PNG 里,
**不往真钥匙串写任何东西**(复用 `InMemoryArchivePasswordBookStorage`,和 `MenuRightApp.swift:534` 那段密码本 PNG 自测同一套)。

## 坑 / 事实

- 沙箱里 `NSHomeDirectory()` 是**容器路径**,所以 `abbreviatingWithTildeInPath` 不会把 `/Users/suxin/...` 缩成 `~/...`;
  上级路径就按原样显示,靠 `.truncationMode(.head)` 保住「当前在哪个文件夹」那一半。
- `CustomCompressionSheet` 的两个 `@State`(`encrypts` / `solid`)**没有**从 `PendingArchiveRequest` 初始化的入口,
  所以自测 PNG 里「加密压缩」永远是未勾状态(钥匙按钮因此是灰的),想截「勾上加密」的样子得真机点。
- 修改器顺序无关紧要,但 `.help()` 要挂在**容器**上:挂到被 `.disabled()` 的控件上,提示不会出现。
