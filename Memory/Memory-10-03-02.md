## 关键决策(理由都在这里,别事后当偶然)

- **样式用 Tailwind CDN**(`https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4`,实际解析到 4.3.3,
  与 `suxin-apps` 编译用的 `tailwindcss ^4.3.3` 同版本),`@theme` 里的令牌逐字抄自
  `suxin-apps/src/styles/global.css`(`--color-surface:#0e0e11` 等)。**这样移植 = 删掉 script 标签
  和 @theme 块,markup 一行不用改**;另留了一份普通 `<style>` 兜底,CDN 挂了页面仍可读。
- **中英双语同存 DOM**(`.lang-zh` / `.lang-en` + `html[data-lang]`),照 `PoopyShell.astro` 的写法,
  选择存 `localStorage["menuright-lang"]`。落地页将来可能同时挂在
  `https://app.ljhsu.xin/menuright` 和 `https://create.ljhsu.xin/menuright`(App 内「产品网站」链接),
  所以链接全用绝对地址,两个域名都能搬。
- **Hero 的右键菜单是 CSS 手搓的 mock**,行与顺序严格照 `MenuRightFinder/FinderMenuBuilder.swift`
  的 `static func plan(...)`(选中项 / 文件夹空白处两个 tab)。菜单文案逐字取自
  `Shared/Settings/Localization.swift`。代码预览块用的是 App 里真实样例

  版本号变了也不用改)。

## 踩过的坑(下次直接避开)

- **Tailwind 的 `peer-checked/*` 是兄弟选择器(`~`)**。菜单 mock 的 radio 和 label 是兄弟,
  但面板是外层 div 的兄弟 → 面板永远不显示(1440 截图里 hero 右侧一片空白才发现)。
  改用卡片上的 CSS `:has()`:
  `#menu-mock:has(#tab-file:checked) .mock-panel-file { display: block; }`
  (Chrome 105+ / Safari 15.4+ / Firefox 121+)。
- **i18n 漏标记**:菜单行写成 `<span>中文</span><span class="lang-en">…</span>`,中文 span 忘加
  `lang-zh`,EN 模式下中英一起显示。用 HTMLParser 栈追踪「CJK 文本节点但没有 lang-zh 祖先」
  才定位到全部 10 处(纯正则匹配会因跨行闭合标签误报)。已批量修 33 处。
- **JS 运算符优先级**:`saved || navigator.language… ? "zh" : "en"` 解析成 `(saved || …) ? …`,
  已保存的 "en" 是真值 → 永远回落 "zh",用户的语言选择**存不住**。必须写成
  `saved === "zh" || saved === "en" ? saved : (prefersZh ? "zh" : "en")`。
- **emoji 当图标在截图里渲染不一致**(🖱️🗜️ 变单色/糊),换成内联 Lucide SVG path(ISC,
  App 里已经致谢过),保持零依赖。
- **读 `getComputedStyle().transform` 要等过渡走完**:`details.open = true` 后立刻读拿到的是
  起始值 `matrix(1,0,0,1,0,0)`,等 0.15s 才是 `matrix(0,1,-1,0,0,0)`(即 rotate(90deg))。
  差点当成 FAQ 箭头不转的 bug。

## 环境事实(可复用)

- 无头 Chrome 在 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`;
  `--window-size` **低于 macOS 最小窗口宽度时不生效** —— 390 宽的截图其实视口约 800px 后被裁掉,
  别据此判断移动端布局坏了(用 CDP `Emulation.setDeviceMetricsOverride` 才是真视口)。
- `--screenshot` 只截视口,不滚到 fragment;注入 `window.scrollTo` 会得到空白图。
  可靠的替代:注入 `<style>main > div > section:nth-of-type(-n+N){display:none}</style>`
  把目标区块顶上来。
- 本轮工具:`web_search` 不可用(DeepSeek API 401),GitHub API 因出口 IP 限流 403,
  所以**没能确认 Releases 是否已经发布** —— 页面里的下载链接是按计划指向 releases/latest 的。
