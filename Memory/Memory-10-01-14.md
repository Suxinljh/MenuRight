## 决策

- **拆成两步**而不是一次做完 P8:`project.pbxproj` 是手工合成 ID 结构,新增 target 风险高;先把可自动验证的引擎落地。
- **高亮器只做预览级**:单遍、无正则、不解析 AST;它要能编进 appex,体积与依赖优先。
- **设置预览与将来的空格预览共用同一引擎、同一份 App Group 主题配置** —— 这是本轮做共享层的主要理由,避免两套配色漂移。

## 踩到并修掉的问题

1. `AttributedString.isEmpty` 在 SwiftUI 环境里被解析成 `K.Value?`(编译报 "optional type cannot be used as a boolean");改为按 `line.text.isEmpty` 提前返回一个空格。
2. 单测里 4 处 `nil`:相邻**同色 token 会被合并**(`name=`、`>Hello`、`id `),`token(text:)` 精确匹配取不到;新增 `contains(_:kind:in:)` 断言包含关系。
3. SQL 关键字表漏了 `true` / `false`,导致 `true` 落到前景色;已补。
4. 往规划文档插入 P8 落地状态时**重复粘贴了 P8 标题段**,已删除重复块(用 `grep -n '^### P'` 复核)。
5. 示例源码只覆盖部分 token 时预览看不出整套配色:给 JavaScript / TypeScript / CSS / YAML / Shell / SQL 的示例补了类型、字符串、数字等行。
