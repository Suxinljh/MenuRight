## 安全规则(这是本轮的重点,全部有测试)

1. `../`、`a/../b`、绝对路径、`C:`、反斜杠、NUL、归一化到根 → 拒绝;**"出去再回来"也拒绝**。
2. 符号链接条目**永不创建**;压缩时**不跟随**符号链接(否则会把没选中的文件打包进去)。
3. **zip bomb 守卫在写盘之前**:先按声明体积求和比对上限,单条超限也拒绝。
4. 逐条 CRC/长度校验,坏条目单独失败、不影响其它条目。
5. **永不覆盖正在读取的那个压缩包**(即使策略是 overwrite)。
6. 元数据(`__MACOSX/`、`.DS_Store`、`._*`)默认跳过,跟随设置。

## 复盘要点

1. **`[UInt8](data)` 会把 `Data` 整个复制**,`mappedIfSafe` 就白用了;改成 `withUnsafeBytes` 单次解析、
   条目按需 `subdata` 之后才是真的按页载入。第一版写完立刻自查发现并重写。
2. `Result<T, ArchiveSkipReason>` 要求 Failure 满足 `Error`;给"跳过原因"加 `Error` 只是为了语法便利,
   已在注释里写明它**不是失败**。
3. 计划器一开始把 `keepBoth` 的重名条目也丢掉了,测试立刻抓出来:去重只应该发生在 `skip` 策略下,
   `keepBoth`/`overwrite` 要保留每一步,由执行层(知道磁盘现状)去编号或覆盖。
4. 恶意压缩包必须**真造**:`ZipWriter` 会拒绝 `../` 名字,所以测试里加了 `RawZipBuilder`
   (仅 STORED、允许任意名字、可标 `S_IFLNK`),验证脚本里用 python `zipfile` 造同样的包。
